1

三段色带刻度

F8

-60~0 dBFS 三段色带：-20 以下绿（正常）、-20~-6 琥珀（预警）、-6~0 红（危险）。色带为静态刻度背景，填充长度由 RMS 驱动。Live 紧凑条与全屏视图共用同一绘制逻辑，仅尺寸参数不同。

2

True Peak · 4× 过采样

F8

对 48kHz PCM 做 4× 过采样插值后取峰，避免采样间峰值漏计。青色竖标 -1.8 dBTP。仅对 POST 抽头（实际发送内容）有意义，PRE 行不显示。

3

闩锁峰值保持 + 重置

F8

白色竖线为峰值保持：到达后保持 1.5s，随后以 6 dB/s 缓慢回落；新峰值超过当前保持值时立即跳变。「重置」同时清零峰值保持与削波 LED。PRE 行保持线弱化显示。

4

削波 LED · 闩锁

F8

POST True Peak ≥ -0.1 dBTP 时点亮并闩锁，不自动熄灭；点击 LED 或「重置」清除。Live 紧凑条右上角为常驻小 LED，全屏视图为按钮级大 LED，两处状态同步。

5

PRE / POST 双抽头

F8保持

PRE 在降噪前采样（原始输入），POST 在 EQ/增益/限幅后采样（实际发送内容）。现有 feedPre / feedPost 双抽头保持；feedPost 挂点随 F6 管线重排移至末级之后。全局静音时数据不进管线，POST 显示 -inf，PRE 正常。

6

LUFS 预留

后续

K 加权 LUFS 集成响度留 MeterMode 枚举位与虚线 UI 入口，本期不实现。走查项：PRE 行无 TP 竖标；静音时 POST 归 -inf；削波 LED 跨视图状态一致。

落地要点：VizRenderer 增加绘制模式分发入口（电平表分支），既有绘制逻辑不动（四视图共用同一 Canvas 与 displaySync，不新建渲染节点）；计量数据由 AudioVizManager 既有 pre/post 缓冲拉取；VizPage 底部分段条四段「电平图 / 波形图 / 电平表 / 涟漪」。页顶增益行为 Live 完整行（刻度 + 气泡），与 live.html / eq.html 同源；Connect 卡内为迷你快捷控件（见 connect.html ⑨）。
