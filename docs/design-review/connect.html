9

输入增益快捷行

F6 新增

降噪行下新增「输入增益」行：±24dB、0.5dB 步进、双击归零，LIMIT 开关启用 brickwall 限制器（默认开，仅超 -0.1dBFS 阈值介入）。系统无硬件增益 API → 软件增益位于 NR 后、发送前（管线 NR→EQ→Gain→Limiter）。本行为迷你快捷控件（滑杆无刻度与气泡），完整增益行（刻度 + 气泡）见 live.html。与 Live 增益行共享 cfgGainDb / cfgLimiterOn，调节后 Live 内嵌电平条与电平表（F8）实时反映。

10

参数均衡器入口

F7 指引

Connect 配置卡不新增 EQ 行 —— 入口在 Live 配置 sheet 的「参数均衡器」折叠行（见 live.html / eq.html）：5 段参量（LowShelf 100Hz + Peaking 300Hz / 1kHz / 3kHz + HighShelf 8kHz）、G ±12dB、Q 0.5~4（Shelf 段置灰）、四预设、总旁通默认开（旁通 = bit 级直通），位于 NR 后 Gain 前。

本页为 running 态（串流中）：主按钮绿色「进入直播」、mini 条可见。idle 态差异：主按钮 accent 蓝「连接 / 开始串流」、mini 条隐藏。
演示配置 48kHz · 16bit · 单声道（弱网自动降级 48k→16k，见 anno2）；电平反馈见 live.html 内嵌电平条与 meter.html。端点 sheet（编辑目标端点）材质与 live.html 配置 sheet 同族，此处不重复展示。
