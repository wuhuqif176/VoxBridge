审核方式

浏览器直接打开各 HTML 文件（无需服务器、无外部依赖），逐页对照标注审核。

  1. 按下方卡片顺序打开 9 份页面草图（建议先看 connect.html 与 arch.html 建立全局，再看 transition.html 转场演示与三张新增专项页 meter / eq / background）
  2. 每个手机框旁的编号标注卡说明该元素的来源阶段（F1~F9 / 保持 / 后续）与关键 API
  3. connect.html 右上角可切换明暗主题；底部页签可点开「设置」查看直播与后台三开关（F9）与麦克风设备（F5）
  4. 反馈格式建议：文件名 + 标注序号 + 意见，例如「eq.html ③ 预设按钮改胶囊」「meter.html ⑧ 刻度补 -45dB」
  5. 草图迭代定稿后才开始 P0~F11 实施；定稿前不改任何代码
材质近似声明：API 26 ImmersiveMaterial 的系统渲染光感（折射 / 高光随内容变化）无法在浏览器复现，草图以 backdrop-filter 模糊 + 半透明底近似示意，最终观感以真机为准。

P0

基线检查点

git 检查点 commit、记录回退锚点 hash、基线 devecocli build 确认（基线警告不新增）。

F1

一镜到底 架构

Live 改 bindContentCover（modalTransition NONE + geometryTransition('liveCard') follow / anchor 对 + animateTo 350ms Curve.Friction）；chevron / 侧滑 = 收起 cover 串流继续；Welcome 改条件覆盖层；VizPage 改二级 cover（退化：vizCoverOpen 提升为 Connect 二级 cover）。

F2

配置 sheet 动效

bindSheet systemMaterial ULTRA_THICK；ConfigSections 折叠行（音源 / 音频参数 / 降噪 + EQ 槽位预留）；curves.springMotion 折叠与上浮动效。

F3

Connect 焕新 材质

module.json5 加 UIMaterial metadata；新建 Materials.ets / UiEnvService.ets；卡片 uiMaterial（style / interactive / lightEffect）；bg_glow 径向渐变；悬浮页签 barFloatingStyle（退化 = 移除）；EndpointSheet 材质。

F4

网络质量 三态 + 自动降级

NetInfoService 评分（bearer / RSSI / 队列水位 / 丢弃率 / 重连计数 → good / fair / weak）+ startWatch / stopWatch；netOnline / netBearer / netQuality key；Connect 三态徽章 + Live 质量 chip；弱网自动降级（CONFIG 帧 48k→16k · 迟滞 + 30s 最短间隔 · 仅采样率维度 · 可关 · 恢复升回）。

F5

帧同步 + 设备 渲染与音频

VizCanvas / VizView 驱动 setInterval 33ms → displaySync 帧同步（expected 60 / min 30 / max 120 · start / stop 成对 · tickCount 节流保留）；AudioSessionManager 设备族 API + 设置页麦克风设备行 + deviceChange 守护 + inputDeviceName key。

F6

管线 + 增益 ±24dB · 限幅

common 新建 AudioPipeline.ets（IAudioStage / GainStage / LimiterStage / BiquadFilter）；StreamService.handleAudioData 重排 NR→EQ→Gain→Limiter→enqueue（静音路径不进管线）；cfgGainDb / cfgLimiterOn key；Connect + Live 增益行 UI；meter_amber 等资源。

F7

参量 EQ 5 段 biquad

common 新建 EqStage.ets（5 段 biquad RBJ · F / G / Q · 旁通 · 预设常量）；cfgEqBypass / cfgEqBands / cfgEqPreset key + preferences 持久化；ConfigSections EQ 折叠面板（曲线预览 + 5 段控件 + 预设 + 旁通）。

F8

电平表 RMS / Peak / TP 4×

AudioVizManager 扩展（truePeak 4× · latchedPeak + 重置 · clipLatch + 重置 · MeterMode 预留 LUFS · feedPost 移管线末级）；VizRenderer / VizCanvas 电平表绘制模式；VIZ_PILL_NAMES「音量」→「电平表」；Live VizCard 内嵌表条 + 削波 LED + 重置。依赖 F5（同一 Canvas / displaySync 管线）。

F9

后台锁屏 AVSession

entry 新建 AvSessionService.ets（createAVSession 'audio' · setAVMetadata（HarmonyMic 直播中 · 端点）· play / pause = 静音切换 · stop = 断开 · 与串流生命周期成对）；KeepScreenOn → 设置开关（默认关）；来电打断自动恢复（audioInterrupt END + cfgAutoRecover 默认开 · 失败 toast 兜底）；设置页三开关行。

F10

打磨 收尾前

状态栏浅字与 Live 同步、colorInvert 页签栏、dark 色板补齐、toast systemMaterial。

F11

全量走查与留痕 收尾

真机走查扩展清单 11 项（转场 / 材质 / 锁屏控制 / 来电恢复 / 弱网降级 / 电平表校准 / EQ 听感 / 增益限幅 / 峰值重置 / 后台 30 分钟稳定性 / 横竖屏）+ MEMORY.md 变动记录。
