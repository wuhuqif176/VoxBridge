实现说明（ArkUI）

几何映射对：连接页 mini 条（follow 端）↔ 直播页 VizCard（anchor 端）· 同 geometryTransition id 成对 · 浏览器演示为近似示意，真机以系统渲染为准

follow 端Connect mini 条

连接页 mini 条卡片：.geometryTransition('liveCard', { follow: true }) + .transition(TransitionEffect.translate({ y: 40 }).combine(TransitionEffect.OPACITY).animation({ curve: curves.springMotion(0.6, 0.85) })) + .id('liveMiniBar')。follow 端跟随几何映射展开。

anchor 端LiveView VizCard

直播页 VizCard：.geometryTransition('liveCard') + .transition(TransitionEffect.opacity(0.99)) + .id('liveVizCard')。anchor 端转场期间 0.99 透明度占位，避免闪烁。

模态载体bindContentCover

Live 以 bindContentCover 弹出，modalTransition 关闭系统默认滑入，展开动画完全交由 geometryTransition 驱动。

动画驱动animateTo

点按 mini 条：animateTo({ duration: 350, curve: Curve.Friction }) 内置位 liveOpen = true。曲线为轻摩擦减速，与系统磨砂材质卡片动效一致。

行为语义收起 ≠ 断开

chevron / 侧滑 = 仅收起 cover，串流继续，mini 条仍在；红色按钮 = stop 串流 + 收起。路由整页销毁重建成为历史。

分段细节：展开时长 350ms（Curve.Friction）；cover 背景磨砂 systemMaterial（API 26 ImmersiveMaterial 就绪后统一为 ULTRA_THICK 材质）；返回收起为同曲线反向；onWillDismiss 保留默认（收起即串流继续，无需二次确认）。浏览器 CSS cubic-bezier(.2,0,.06,1) 仅近似 Curve.Friction，真机节奏以系统插值为准。
